## 2026-07-14 - Route-based Code Splitting
**Learning:** The application bundle size was unnecessarily large because all route components (Home, About, Services, Contact, References, Legal, etc.) were synchronously imported in `App.tsx`. Implementing route-based code splitting using `React.lazy` and `Suspense` reduced the main bundle size from 477.36 kB to 376.95 kB, chunking out page components to separate files that load on demand.
**Action:** Use `React.lazy` and `Suspense` for routing components to improve initial load time by loading non-critical code asynchronously. Note that page components here use named exports (e.g., `export const Home = () => ...`) instead of default exports, so the explicit mapping `import(...).then(m => ({ default: m.Home }))` was required for `React.lazy()`, except for `NotFound` which correctly uses a default export.
