## 2026-04-23 - [React Re-renders in High-Frequency Animations]
**Learning:** The application was using React `useState` and `setInterval` to animate numerical counters (`AnimatedNumber.tsx`), causing a full React render cycle every 16ms for every counter instance on the page. This is a severe anti-pattern in React because it forces the reconciliation engine to work unnecessarily on every frame, which can cause jank on lower-end devices or when many counters are present.
**Action:** Always use a direct DOM manipulation strategy (like `motion/react`'s `animate` function combined with a `ref`) for high-frequency animations (like number counters or tracking mouse positions) to completely bypass the React render tree. Ensure that `controls.stop()` is returned in the `useEffect` cleanup to prevent memory leaks if the component unmounts mid-animation.
