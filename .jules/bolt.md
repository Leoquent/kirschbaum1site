## 2024-05-15 - React Code Splitting for Router Pages
**Learning:** Using React.lazy and Suspense for code splitting route components drastically reduces the initial Javascript bundle size since users no longer load pages they don't visit on the first load. When using `React.lazy()` with components that use named exports instead of `export default` (which is standard for this app's page components except `NotFound`), you must explicitly map the module to an object with a default property (e.g. `React.lazy(() => import('./pages/Home').then(module => ({ default: module.Home })))`).
**Action:** When working on performance optimizations for React routing in this app, implement Route level code-splitting using `React.lazy` and `Suspense`, but always map named exports appropriately to prevent breaking standard importing mechanisms.
