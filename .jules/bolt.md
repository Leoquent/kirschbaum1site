## 2024-10-24 - Route Code Splitting
**Learning:** Found that all page components (Home, About, Contact, Services, References, Legal) were imported synchronously in `src/App.tsx`. This causes the initial bundle size to be much larger than necessary since the user downloads all page code on first load, even if they never visit those routes. The codebase's architecture dynamically wraps page content with a `<Layout>`, requiring the `<Suspense>` fallback to also be wrapped in `<Layout>` to avoid layout shift/thrashing during route transitions. Most page components in this project use named exports, which require mapping to `.default` when lazy loading.
**Action:** Use `React.lazy` and `Suspense` for all top-level routes in `App.tsx` and map named exports correctly. Wrap the `Suspense` fallback in the `<Layout isStatic={true}>` component to maintain UI consistency during chunk loads.
