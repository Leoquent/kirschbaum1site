## 2024-04-13 - Avoid useState + setInterval for High-Frequency Animations
**Learning:** Using `setInterval` combined with React's `useState` for animating numbers (like counters) triggers a component re-render every 16ms (60fps). This severely degrades main thread performance by forcing React through its entire render and reconciliation cycle up to 60 times a second for a simple text update.
**Action:** When animating values that frequently update the DOM, use `motion/react`'s `animate` function combined with a direct DOM mutation on a `ref.current.textContent`. This completely bypasses React's render cycle, achieving the same visual effect with near-zero overhead. Always remember to return a cleanup function (`controls.stop()`) from `useEffect` to prevent memory leaks when the component unmounts.
