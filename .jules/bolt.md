## 2024-05-24 - High-frequency animations and React renders
**Learning:** High-frequency animations (like a number counter ticking up rapidly using `setInterval` and `useState`) cause unnecessary React re-renders for every single tick. In an interval of 16ms, this triggers 60 re-renders per second, degrading performance. Using Framer Motion's `animate` function allows direct DOM manipulation (e.g., modifying `ref.current.textContent`) to update the value, entirely bypassing React's render cycle while preserving consistent animation speed.
**Action:** When implementing high-frequency animations such as progress bars or number counters, use `motion/react`'s `animate` function with `ease: "linear"` to directly update a DOM ref's textContent/value, rather than relying on React state updates. Always remember to return a cleanup function (e.g., `return () => controls.stop();`).
