## 2026-05-28 - Optimize High-Frequency Animations to Bypass React Render Cycle
**Learning:** High-frequency animations (like number counters updating every 16ms) implemented using React state (`useState`) cause excessive component re-renders, significantly degrading performance, especially when placed in larger page components.
**Action:** When animating values frequently, use `motion/react`'s `animate` function combined with an `onUpdate` callback to directly mutate the DOM node (e.g., `ref.current.textContent = ...`). This completely bypasses the React render cycle while maintaining smooth 60fps animations. Always return the stop function from `animate` as the `useEffect` cleanup to prevent memory leaks and ensure the `onComplete` callback fires to set the final exact value.
