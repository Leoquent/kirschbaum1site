## 2025-03-01 - [High-Frequency Animation DOM Manipulation]
**Learning:** High-frequency animations (like number counters) can trigger an excessive amount of React re-renders if managed with `setInterval` and `useState` (e.g., 60 updates/sec * 4 counters = ~240 re-renders/sec). This causes immense overhead. By using `motion/react`'s `animate` function on a ref with `ease: "linear"`, you can directly manipulate the DOM nodes (e.g. `ref.current.textContent`) to completely bypass React's render cycle while still achieving a smooth animation.
**Action:** When working with continuous animations that don't need to trigger cascading component updates or complex layout recalcs, always opt for direct DOM manipulation (e.g., using refs with Framer Motion's imperative `animate` or vanilla JS) instead of driving the animation loop with React state.
