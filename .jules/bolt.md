## 2025-02-27 - [Direct DOM manipulation for high-frequency animations]
**Learning:** Using React state (useState) inside a rapid setInterval to animate numbers causes severe performance issues (re-rendering the entire component tree on every frame). Using Framer Motion's `animate` function to directly mutate `ref.current.textContent` is much more efficient and bypasses the React render cycle completely.
**Action:** For high-frequency visual updates (like counting numbers, progress bars that don't need semantic React state), prefer direct DOM manipulation via refs and Framer Motion's `onUpdate`/`animate` APIs over React state updates. Ensure the initial render includes a default value (e.g., `<span ref={ref}>0</span>`) to prevent visual regressions before the animation starts, and always return a cleanup function (`controls.stop()`) to avoid memory leaks.
