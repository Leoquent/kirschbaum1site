## 2026-05-21 - Avoiding React Re-renders in High-Frequency Animations
**Learning:** Using React state (`useState`) to drive 60fps animations (like number counters via `setInterval`) is a major performance anti-pattern. Updating state every 16ms triggers ~120 React re-render cycles for a 2-second animation. This blocks the main thread, causing jank and layout thrashing, especially when multiple such components render simultaneously.
**Action:** When animating values at high frequencies, completely bypass React's render cycle. Use `motion/react`'s `animate` function combined with a React `ref` to mutate the DOM directly (e.g., `ref.current.textContent = Math.round(value)`). Always return the `stop` function from `animate` in `useEffect`'s cleanup to prevent memory leaks and ensure exact completion with `onComplete`.
