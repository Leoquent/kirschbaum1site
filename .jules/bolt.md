## 2025-03-05 - Bypassing React renders for high-frequency animations
**Learning:** In a codebase using Framer Motion (`motion/react`), using standard React state (`useState` + `setInterval` or `requestAnimationFrame`) to drive high-frequency text updates (like a number counter) causes severe main thread blocking due to hundreds of unnecessary React render cycles.
**Action:** When animating values that just need to update text content, use `motion/react`'s `animate` function combined with a `useRef` to directly manipulate the DOM node (`ref.current.textContent`). This completely bypasses the React render cycle, resulting in massive performance gains with zero visual difference. Note that for Framer Motion v12, the `duration` parameter in `animate` must be specified in seconds.
