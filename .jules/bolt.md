## 2024-05-24 - [Avoid React State for High-Frequency Animations]
**Learning:** Using React state (`useState`) within a `setInterval` or `requestAnimationFrame` loop for rapid value changes (like a number counter) triggers hundreds of unnecessary re-renders, creating a significant performance bottleneck. Additionally, when using Framer Motion v12's standalone `animate` function directly on a DOM node (to bypass React renders), the `duration` parameter must be provided in seconds, not milliseconds as it might be in other contexts or older versions.
**Action:** Use Framer Motion's `animate` function to directly mutate `ref.current.textContent` for high-frequency updates, achieving O(0) React renders during the animation. Always check motion version documentation for unit requirements (seconds vs ms) when using standalone functions.
