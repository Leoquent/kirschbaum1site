## 2026-07-30 - [Bypass React State for High-Frequency Animations]
**Learning:** High-frequency animations (like number counters) using `useState` and `setInterval` in React components cause excessive re-renders, impacting performance. `motion/react` provides an `animate` function that can be used directly on DOM node refs to bypass the React render cycle entirely while preserving consistent animation speed.
**Action:** When implementing high-frequency UI updates like number counters, use `motion/react`'s `animate` function on a DOM ref (e.g., `ref.current.textContent`) with `ease: "linear"`, instead of React's `useState`. Remember to set default text content (e.g., `0`) to avoid visual regressions, specify `duration` in seconds (not milliseconds), return a cleanup function (`controls.stop()`) to avoid memory leaks, and use `onComplete` to set the exact final value.
