## 2026-05-13 - [Performance Optimization: React State vs. Direct DOM Manipulation in High-Frequency Animations]
**Learning:** Using React state (e.g., `useState`) within rapid `setInterval` loops (like a 16ms tick for a 2-second number counter) forces the React render cycle to trigger repeatedly (~120 times per element), leading to significant main thread blocking and jank.
**Action:** When implementing high-frequency animations such as number counters, use a library like `framer-motion` (via `motion/react`'s `animate` function) to directly manipulate the DOM node (`ref.current.textContent`). This bypasses the React render cycle entirely while preserving the desired visual effect and improving performance. Always include an `onComplete` callback to ensure the final exact value is set properly, and ensure lifecycle hygiene by stopping the animation control during cleanup (`controls.stop()`).
