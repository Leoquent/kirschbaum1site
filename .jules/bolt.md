## 2024-10-24 - Route-level code splitting with custom fallback
**Learning:** When applying route-level code splitting with `React.lazy` and `Suspense` in this architecture where individual page components render the `<Layout>` component, the `Suspense` fallback must also be wrapped in the `<Layout>` component (e.g., `<Layout isStatic={true}>...`) to prevent the header and footer from disappearing during the loading state. Also, since most pages use named exports, they require explicit mapping: `React.lazy(() => import('./pages/Home').then(module => ({ default: module.Home })))`.
**Action:** Always verify the structure of page components (whether they wrap layout or are wrapped by it, and default vs named exports) before implementing `Suspense` boundaries to ensure UI consistency during chunk loading.
