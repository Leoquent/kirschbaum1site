## 2024-05-14 - Direct DOM Manipulation for High-Frequency Animations
**Learning:** Found a component (`AnimatedNumber`) that was triggering state updates every 16ms to animate a counter. In React, this causes excessive and unnecessary re-renders for the component and its children (~125 re-renders per number counter over 2 seconds). Since this is purely a visual effect, React's render cycle doesn't need to be involved.
**Action:** When implementing high-frequency animations (like number counters, scroll progress, drag positions), use `motion/react`'s `animate` function combined with a `useRef` to directly modify the DOM node (e.g., updating `ref.current.textContent`). This reduces render cost to O(1) and significantly improves performance without changing functionality. Ensure `duration` is in seconds for Framer Motion v12.
