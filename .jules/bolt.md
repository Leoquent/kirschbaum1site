## 2025-02-19 - Adding Code Splitting via React.lazy and Suspense
**Learning:** Code splitting route components significantly reduces the initial bundle size of a React application. By leveraging `React.lazy` and `Suspense`, we can defer loading pages until they are actually visited, which improves the time-to-interactive for the user, especially on slower networks.
**Action:** Always consider code splitting route components as a standard practice for larger React applications to keep the main bundle lightweight.
