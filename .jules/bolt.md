## 2025-02-26 - Bypassing React Render Cycle for High-Frequency Animations\n**Learning:** The AnimatedNumber component was causing ~120 unnecessary re-renders per instance during its 2-second animation by tying standard `setInterval` counter updates to React state (`useState`).\n**Action:** Direct DOM manipulation via `ref.current.textContent` combined with Framer Motion's `animate` function eliminates these re-renders entirely while maintaining the exact visual effect.
