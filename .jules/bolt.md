## 2026-09-24 - Bundle Size Reduction via Route-Level Code Splitting
**Learning:** This React single-page application had all its route components (Home, About, Services, Legal, etc.) statically imported in `src/App.tsx`. Because Vite and Rollup treat static imports as dependencies of the entry point, the entire application was being compiled into a single massive JavaScript chunk (approx 477 kB), meaning users had to download the whole app just to view the landing page.
**Action:** When working on React applications with `react-router-dom`, always check the root routing component (like `App.tsx`) to ensure page-level components are imported dynamically using `React.lazy()` and wrapped in `<React.Suspense>`. This allows the bundler to split the application into smaller chunks, loading only the necessary code for each route, significantly improving initial load times.
