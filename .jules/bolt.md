## 2024-03-10 - Bypassing React State for High-Frequency Animations
**Learning:** Using React state (e.g., `useState`) inside an animation frame or high-frequency interval (`setInterval`) causes excessive and costly component re-renders. This is particularly problematic for simple numerical counters where the DOM only needs a text update, as React's reconciliation process overhead outweighs the benefit of state management.
**Action:** When implementing high-frequency animations (like number counters) with Framer Motion, bypass React state updates. Instead, use a React `ref` and Framer Motion's `animate` function to directly mutate the DOM element's `textContent` inside the `onUpdate` callback, ensuring smooth performance and eliminating unnecessary render cycles. Always include an `onComplete` handler to set the exact final value, and provide a default initial state in the JSX (e.g., `<span ref={ref}>0</span>`).
