## 2026-08-04 - React Render Cycle Bypass for High-Frequency Animations
**Learning:** High-frequency animations like counting numbers should not rely on React state (`useState` inside `setInterval`), as they cause unnecessary 60fps re-renders of the component tree. Framer Motion's `animate` function provides a much better approach by updating the raw DOM node directly (`ref.current.textContent`) combined with `ease: "linear"`, bypassing React's render cycle completely. This ensures consistent animation speed without blocking the main thread.
**Action:** When animating values frequently, use DOM ref mutations instead of React state. Always initialize components relying on DOM mutation with the correct default value (e.g., `<span ref={ref}>0</span>` instead of `<span ref={ref} />`) to avoid FOUC or visual regressions. Also, always add an `onComplete` block setting the exact final value to prevent floating point inaccuracies.
