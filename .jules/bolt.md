## 2026-05-31 - [High-Frequency Animation State Anti-Pattern]
**Learning:** Using `useState` combined with `setInterval` to drive high-frequency animations (like number counters over a 2-second duration) is a significant performance anti-pattern in React. It causes excessive re-renders (e.g., 60+ times per second per component), blocking the main thread and causing scroll jank.
**Action:** For high-frequency, purely visual DOM updates, bypass the React render cycle completely. Use `motion/react`'s `animate` function to directly update the DOM node's properties (e.g., `ref.current.textContent = value`) inside a `useEffect`. Ensure the duration is specified in seconds, use `onComplete` for the final exact value, and always return a cleanup function (`controls.stop()`) to prevent memory leaks if the component unmounts.
